## 🌟 Overview

**CMFI Rwanda Church Website** is a production-ready, full-stack web application designed for religious organizations to establish a modern online presence. The platform features a responsive React frontend with dark mode, a secure Spring Boot backend, and automated email notifications for contact form submissions.

This project demonstrates proficiency in modern web development technologies including React Hooks, Spring Boot REST APIs, JPA/Hibernate, PostgreSQL, and secure email integration using Gmail SMTP.

### 🎯 Purpose
- Provide the church with an elegant, maintainable web solution
- Demonstrate best practices in security, responsive design, and API development

## ✨ Features

### Frontend (React + Vite)
| Feature | Description |
|---------|-------------|
| 🎨 **Responsive Design** | Mobile-first layout that works on all devices |
| 🌙 **Dark/Light Mode** | User preference saved in localStorage |
| 📱 **Mobile Navigation** | Hamburger menu for seamless mobile experience |
| ✨ **Smooth Animations** | Intersection Observer for fade-in effects |
| 🧩 **Component-Based** | 12+ reusable React components |
| ⚡ **Fast Builds** | Vite for lightning-fast HMR and optimized builds |
| 📧 **Contact Form** | Integrated with backend email service |
| 💬 **Testimonials Slider** | Interactive testimonial carousel |
| 🎯 **Smooth Scroll** | Navigation with smooth scrolling to sections |

### Backend (Spring Boot)
| Feature | Description |
|---------|-------------|
| 🔐 **Secure Email** | Gmail SMTP with app password authentication |
| 📝 **Form Validation** | Server-side validation for contact submissions |
| 🌐 **CORS Configured** | Allows frontend communication |
| 🏥 **Health Check** | Monitoring endpoint for uptime tracking |
| 🔄 **RESTful API** | Clean, well-structured endpoints |
| ⚡ **Fast Response** | Optimized for quick email delivery |
